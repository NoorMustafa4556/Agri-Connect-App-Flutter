# 🚜 AgriConnect – Farm Equipment Rental App (Flutter)

**AgriConnect** is a modern Flutter application designed to bridge the gap between farm equipment owners and farmers. Its mission is to empower the agricultural community by providing a decentralized platform where farmers can easily find, request, and rent machinery (like tractors, harvesters, and seeders) from local owners, boosting productivity and reducing farming costs.

The app offers dedicated role-based dashboards, location-based equipment filtering, secure Firebase authentication, and a clean, nature-inspired green UI — all powered by Firebase for lightning-fast real-time database updates.

---

## Why AgriConnect?
For many small to medium-scale farmers, purchasing heavy farm machinery is financially out of reach. AgriConnect solves this by creating a localized sharing economy. Equipment owners can monetize their idle machinery, and farmers can rent what they need, exactly when they need it. It's a win-win for the agricultural ecosystem!

---
## 🚀 Key Features
- **Role-based Experience** – Separate, tailored dashboards for Farmers & Equipment Owners.
- **Dynamic Equipment Library** – Owners can dynamically browse and associate local visual assets for their listings.
- **Smart City Filtering** – Farmers can instantly filter available equipment by city and category.
- **Secure Firebase Backend** – Protected User Authentication (Email/Password) & Cloud Firestore data management.
- **Complete Profile Management** – Edit profiles, locations, and contact information seamlessly.
- **Elegant "Agriculture Green" UI** – A refreshing, responsive, and modern interface.
- **Real-Time Booking Flow** – (In-progress) Farmers request equipment, and Owners receive and manage these requests.
- **Offline-First Resilience** – Smooth form validation and error handling.

---
### 🔐 Role-Based Access
- **Equipment Owners** → Add new equipment, set prices, and manage rental requests.
- **Farmers** → Browse categories, filter by city, and request machinery securely.

### 🔎 Smart, Real-Time Search
- **Farmers** can search and filter the live database instantly based on:
  - City / Area
  - Equipment Category (Tractor, Harvester, Plough, etc.)

### 👤 Secure Account Management
- Streamlined sign-up with dynamic role toggles.
- Auto-login persistence using Firebase Auth state changes.
- Secure side-drawer navigation.

### 🎨 Modern UI/UX
- "Agriculture Green" primary color scheme tailored for the farming theme.
- Clean navigation with custom Drawer (Home, Profile, History, Logout).
- Smooth user feedback with snackbars, loading indicators, and modern form validations.
